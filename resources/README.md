## Microsoft Student Ambassadors attribution

Some official Microsoft Learn links include the maintainer's Student Ambassadors contributor parameter (`wt.mc_id=studentamb_475517`). This attributes genuine visits to eligible Microsoft resources but does not guarantee a **Preferred Visitor** count. Microsoft Learn Plans do not qualify for Preferred Visitors. Third-party links and machine-readable source URLs remain unchanged. This project is independent and not endorsed by Microsoft.

**Verification checklist:** confirm that each attributed link resolves to the intended official resource, retains original query parameters, contains the ID exactly once, and matches current MSA eligible paths. Do not automate clicks or generate artificial visits.

## Trust and reuse

The guide defines exam scope. Official education and documentation support explanations. Curated community sources add teaching options; popularity is not proof of accuracy. Unverified auxiliary content is a supported trust category but is intentionally absent from this initial catalog.

We link to third-party material; we do not redistribute their courses, handouts or questions. Microsoft and community authors retain rights to their material. Do not submit exam dumps or material claiming to reproduce confidential exam questions.

## Português

Você pode estudar inteiramente em português. Peça ao tutor explicações em português, mantendo os nomes atuais dos serviços em inglês quando isso ajudar a reconhecer a documentação e a prova. O guia inglês define o escopo deste currículo; provas localizadas podem receber atualizações depois. Confirme a versão e o idioma ao agendar.

## Curating an addition

Record a stable ID, canonical URL, author, format, language, cost, domain/competency scope, publication date if known, date and depth of verification, authority, editorial rationale and limitations. Use an empty competency list for broad hubs whose bullet-level coverage has not been audited. A resource mapping means it is useful for the area, not that every sentence has been verified or that it covers the entire competency. Prefer a targeted official source over many duplicative links.

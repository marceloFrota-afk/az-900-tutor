# Original practice bank

`questions.json` contains 30 original Portuguese scenarios (9 cloud concepts, 12 Azure architecture/services, 9 management/governance). Tutors can translate prompts while retaining service names, the distinction tested, and scoring criteria. Seven items are multiple choice with rationales for every distractor; the rest require explanation, comparison, or application. All items request reasoning. They are teaching exercises, not recalled or simulated confidential Microsoft questions.

Each item maps one primary competency ID to conceptual Microsoft Learn sources. Linked modules/paths support the concepts, not a claim that Microsoft authored or endorsed the item. `verified_at` records source inspection, not independent validation of the question. A second AI agent independently reviewed all 30 prompts, keys, rubrics, distractors and primary competency mappings against official conceptual sources on 2026-10-15. That review clarified the SMB requirement in Q016 (Blob also supports NFS in some configurations) and Reader control-plane scope in Q021. Human Azure subject-matter review, learner trials, difficulty calibration and item-discrimination statistics remain pending.

Present only prompt/options before the response. Keep answers, rubrics, and rationale tutor-side. Give feedback afterward, unless a simulation defers it. The 0–3 rubric is normalized by dividing by 3 before recording a CLI score. A correct letter without explanation is recognition evidence and does not receive full rubric credit. A contradiction in the learner's reason should trigger misconception repair even if the choice was correct.

The bank deliberately samples 30 distinct competencies, not all 57. Missing coverage includes cloud definition, deployment use cases/pricing details, security/governance/manageability benefits, several architecture/VM/network details, account and file-movement tools, Entra services/external identities/Conditional Access/Zero Trust/defense in depth/Defender, cost factors, Purview, portal/shell interfaces, IaC fundamentals, and Advisor. Use `exam/curriculum.json` to identify every unassessed objective. Add source-grounded original scenarios for gaps and record them as new prompts; do not reinterpret a sample score as comprehensive coverage.

Repeated exposure to these 30 items makes scores less informative. A readiness assessment needs fresh scenarios, delayed retrieval, and coverage outside the bank. A practice percentage does not translate to the official scaled exam score or a probability of passing.

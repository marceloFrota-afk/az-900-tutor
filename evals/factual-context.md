# Shared factual packet for paired development probes

This packet controls factual availability for both conditions. It contains facts and public sources, without the tutor's pedagogical instructions. It is not a complete Azure course. Sources were retrieved on 2026-10-15 during development.

- Current exam scope: effective 2026-07-20, 57 objectives; cloud concepts 25–30%, architecture/services 35–40%, management/governance 30–35%. [Guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-900).
- Azure IaaS VMs: customer manages guest OS updates and workload, provider manages physical infrastructure. Managed PaaS platform OS is provider managed. Customers still manage their identities/access decisions and data in SaaS. [Shared responsibility](https://learn.microsoft.com/en-us/azure/security/fundamentals/shared-responsibility).
- Functions executes event-driven code on managed infrastructure. Serverless still uses servers; hosting plan affects scaling, billing and operating limits. Q012 is an original tutor-bank event-driven compute question, key B = Azure Functions. Q001 concerns shared responsibility. No previous student files or learner attempts are supplied. [Compute module](https://learn.microsoft.com/en-us/training/modules/describe-azure-compute-networking-services/).
- Resource groups contain resources; subscriptions contain resource groups; management groups organize subscriptions. Entra authentication establishes identity; Azure RBAC authorizes resource actions at scopes. Reader configuration visibility does not by itself grant stored-data access. Policy evaluates/enforces resource rules; resource locks protect control-plane changes, not data-plane deletion. [RBAC](https://learn.microsoft.com/en-us/azure/role-based-access-control/overview), [Policy](https://learn.microsoft.com/en-us/azure/governance/policy/overview), [locks](https://learn.microsoft.com/en-us/azure/azure-resource-manager/management/lock-resources).
- Availability and service support vary across regions. Zones isolate facilities within a region; not all regions/services offer the same zone support. Region pairs are not universal. [Regions](https://learn.microsoft.com/en-us/azure/reliability/regions-overview).
- App Service, containers and VMs can all host web workloads. OS control, runtime compatibility and operational constraints affect choice; merely knowing it is web does not uniquely determine hosting. [Hosting module](https://learn.microsoft.com/en-us/training/modules/describe-azure-compute-networking-services/).
- Official public practice is available; no confidential exam content is included. [Practice Assessment](https://learn.microsoft.com/en-us/credentials/certifications/practice-assessments-for-microsoft-certifications).

Tools available in both conditions include local file reads and web lookup; neither condition is asked to deploy resources or contact a student. Model deployment version and sampling settings are not exposed by this environment.
